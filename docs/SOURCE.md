| 项 | 值 |
| --- | --- |
| 官方文档站点 | https://x-docs.rokid.com/docs/ |
| 快速开始 | https://x-docs.rokid.com/docs/terminal-sdk/getting-started/快速开始.html |

| 眼镜端 SDK | `com.rokid.security:glass3.open.sdk:2.2.0-E` |
| 手机端 SDK | `com.rokid.security:phone.sdk:2.2.0-E` |
| 推荐 OTA | `1.19.e006-20260806-150201` 及以上 |

官方 Skill 包安装在 `.cursor/skills/rokid-glass3-sdk/`（`SKILL.md` + `references/` + `scripts/`）。`docs/official/` 是指向该目录的符号链接。接口名、参数、版本号以 Skill 内公开文档为准，不要凭记忆补全未公开 API。
