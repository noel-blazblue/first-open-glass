# 指环连接

## 示例说明

演示如何在手机端扫描、连接和展示眼镜配套指环设备状态。

## 使用位置

手机端设置页：

- `SettingActivity` -> `DeviceLinerActivity`

示例页面：

- `com.rokid.phone.ui.DeviceLinerActivity`

## 适用端

- 手机端

## 关键文件

- `glass3sdkphonedemo/app/src/main/java/com/rokid/phone/ui/DeviceLinerActivity.kt`
- `glass3sdkphonedemo/app/src/main/java/com/rokid/phone/ui/DeviceLinkerAdapter.kt`

## 流程说明

<div class="sample-flow">
  <div class="sample-flow-step" data-step="1">
    <strong>注册监听</strong>
    <span>页面初始化时注册 <code>IBTRingClientListener</code>。</span>
  </div>
  <div class="sample-flow-step" data-step="2">
    <strong>扫描指环</strong>
    <span>调用 <code>startScan()</code> 扫描符合过滤条件的设备。</span>
  </div>
  <div class="sample-flow-step" data-step="3">
    <strong>连接设备</strong>
    <span>用户点击列表项后调用 <code>connectToServer()</code>。</span>
  </div>
  <div class="sample-flow-step" data-step="4">
    <strong>刷新状态</strong>
    <span>根据连接回调更新页面中的指环状态。</span>
  </div>

1. 页面注册 `IBTRingClientListener`。
2. 调用 `startScan()` 扫描符合过滤条件的指环设备。
3. 展示可连接列表。
4. 用户点击连接后调用 `connectToServer()`。
5. 监听连接结果并更新 UI。

## 注意事项

- 当前扫描过滤条件是固定的设备名列表：`D01`、`D06`。
- 页面中同时展示“当前已连接/已断开”的指环状态。
- 如果关闭连接开关，页面会停止扫描并断开当前指环连接。
