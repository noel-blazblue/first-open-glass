# 手机端接收消息与文件

## 示例说明

演示手机端如何接收来自眼镜的文本消息、文件和蓝牙音频流。

## 使用位置

手机端首页：

- `MainPhoneActivity` -> `MessageReceiveActivity`

示例页面：

- `com.rokid.phone.MessageReceiveActivity`

## 适用端

- 手机端

## 关键文件

- `glass3sdkphonedemo/app/src/main/java/com/rokid/phone/MessageReceiveActivity.kt`
- `glass3sdkphonedemo/app/src/main/java/com/rokid/phone/utils/ExternalAudioPlayer.kt`

## 流程说明

1. 页面初始化时注册 `IMessageListener`。
2. 同时为 P2P 和蓝牙文件接收器注册 `FileReceiveListener`。
3. 接收到文本时输出日志。
4. 接收到蓝牙音频流时，交给 `ExternalAudioPlayer` 播放。

## 接收能力

- 经典蓝牙文本消息
- P2P 文本消息
- 蓝牙流数据
- 文件接收

## 注意事项

- 页面更适合作为“接收链路验证页”，不是最终用户界面。
- 如果你要用于正式业务，建议把日志输出替换为更明确的数据展示和状态反馈。
