# 车牌识别

## 示例说明

演示眼镜端如何启动车牌识别模式，并实时展示识别结果。

## 使用位置

眼镜端首页：

- `HomeActivity` -> `GlassLprTrackActivity`

示例页面：

- `com.rokid.glass.GlassLprTrackActivity`

## 适用端

- 眼镜端

## 关键文件

- `glassdemo/app/src/main/java/com/rokid/glass/GlassLprTrackActivity.kt`

## 流程说明

1. 注册 `IGlassDetectionListener`。
2. 调用 `startDetection(MODE_LPR)` 启动车牌识别。
3. 在 `onLPRTrack()` 中接收车牌识别结果。
4. 页面持续输出：
   - 车牌号
   - 车牌颜色
   - 识别分数

## 实现说明

### 结果处理方式

没有。

当前页面主要做实时识别展示和日志输出，方便快速验证模型是否工作正常。

## 注意事项

- 页面退出时需要显式停止检测。
- 如果你要做业务闭环，通常还需要补抓拍、结果上传和轨迹管理。
