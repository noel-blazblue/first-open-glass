# 眼镜端相机画面共享与混流录像

## 示例说明

演示眼镜端应用如何选择相机画面共享模式，并完成相机画面与界面叠加的混流录像。

## 使用位置

眼镜端消息发送页：

- `SendMessageActivity` -> `CameraShareSelectActivity`

示例页面：

- `com.rokid.glass.CameraShareDemoActivity`

## 适用端

- 眼镜端

## 关键文件

- `glassdemo/app/src/main/java/com/rokid/glass/CameraShareSelectActivity.kt`
- `glassdemo/app/src/main/java/com/rokid/glass/CameraShareDemoActivity.kt`
- `glassdemo/app/src/main/java/com/rokid/glass/camera/MixRecordFragment.kt`
- `glassdemo/app/src/main/java/com/rokid/glass/camera/SurfaceShareFragment.kt`

## 流程说明

1. 在 `SendMessageActivity` 中点击相机画面共享入口。
2. `CameraShareSelectActivity` 选择 Surface、NV21 或 Mix 模式。
3. `CameraShareDemoActivity` 根据所选模式加载对应 Fragment。
4. Mix 模式由 `MixRecordFragment` 使用 `CameraShareHelper` 获取相机画面，并写入混流 MP4。
5. Surface 模式由 `SurfaceShareFragment` 展示相机画面共享效果。

## 实现说明

### 与 SDK 拍照录像页的区别

`SdkMediaActivity` 用于演示基础 SDK 拍照、录像和录音能力。

本示例用于演示相机画面共享与混流录制，包含：

- 模式选择与触控板切换
- 相机画面 Surface 共享
- NV21 数据导出与相机/界面混流录像

### 适用场景

当业务需要将相机画面提供给应用界面、叠加内容后录制，或处理 NV21 数据时，更适合参考本示例。

## 注意事项

- 进入后台或页面销毁时必须释放相机共享和录像资源。
- 交互依赖眼镜触控板键值。
- 录像参数会影响预览分辨率、帧率和性能表现。
