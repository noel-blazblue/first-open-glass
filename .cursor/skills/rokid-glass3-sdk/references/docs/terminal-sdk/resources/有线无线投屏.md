# 投屏工具

Glass3 支持无线和有线两种投屏方式，可用于演示、远程排查和开发调试。

## 无线投屏 RokidMirror

推荐优先使用 RokidMirror 投屏小助手配合企业版系统内置的**扫一扫**应用。眼镜扫描电脑端二维码后，可连接目标 Wi-Fi、临时开启无线 ADB，并自动启动投屏。

- [RokidMirror 使用、下载与排查](./RokidMirror无线投屏.md)
- [RokidMirror 版本记录](./RokidMirror版本记录.md)

## 有线投屏

开发者可以通过 Glass3 数据调试线和 `scrcpy` 直接投屏。这种方式适合首次安装、网络不可用或需要稳定调试连接的场景。

- [有线投屏使用方式](./有线投屏.md)
