# 有线投屏

`scrcpy` 是一个开源的 Android 设备投屏和控制工具。独立使用 `scrcpy` 时，需要先安装 `scrcpy`，并配置可用的 [`adb` 环境](./使用手册与常用资料.md#配置-adb-环境)。使用有线方式时，通过 **Glass3 数据调试线** 连接眼镜和电脑，把眼镜画面实时投到电脑上。

## 有线投屏步骤

1. 使用 Glass3 数据调试线连接眼镜和电脑。
2. 执行下面的命令确认电脑已经识别眼镜：

```bash
adb devices
```

3. 看到眼镜设备状态为 `device` 后，启动投屏：

```bash
scrcpy -s <眼镜设备序列号>
```

如果电脑只连接了一台 Android 设备，也可以直接执行：

```bash
scrcpy
```

## 开发者可选：手动切换为无线 ADB

需要手动排查无线 ADB 时，可先用数据线连接眼镜，再执行以下命令。普通用户无需使用这组步骤，建议直接使用 [RokidMirror 无线投屏](./RokidMirror无线投屏.md)。

1. 确认设备在线：

```bash
adb devices
```

2. 开启 ADB TCP 连接端口：

```bash
adb tcpip 5555
```

3. 查看眼镜 `wlan0` 网卡地址：

```bash
adb shell ip addr show wlan0
```

4. 连接眼镜并启动投屏：

```bash
adb connect <眼镜IP>:5555
scrcpy -s <眼镜IP>:5555
```

### 常见问题

| 现象 | 建议排查 |
| --- | --- |
| `adb devices` 看不到眼镜 | 确认使用的是 Glass3 数据调试线，并检查 USB 调试状态。 |
| `adb connect` 失败 | 确认电脑能够访问眼镜 IP，网络未隔离设备互访，也没有被防火墙拦截。 |
| 投屏画面卡顿 | 切换到更稳定的 Wi-Fi，或恢复使用有线投屏。 |
| 重启后无线连接失效 | 部分环境重启后需要重新通过数据线执行 `adb tcpip 5555`。 |
