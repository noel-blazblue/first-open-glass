# RokidMirror 版本记录

本页集中记录 RokidMirror 桌面投屏助手的功能变化、稳定性优化和升级注意事项。安装与日常使用方法请查看：[无线投屏 RokidMirror](./RokidMirror无线投屏.md)。

## 1.1.9

- 改善 macOS 和 Windows 的 ADB 启动、USB 接管及切换网络后的恢复稳定性。
- 投屏任务与 Android Studio 等开发工具的 ADB 会话相互隔离，失败恢复只处理当前眼镜。
- 减少 macOS 升级后重复出现钥匙串密码授权弹窗的问题。
- 桌面助手统一为 `1.1.9`；备用扫码投屏 APK 更新为 `1.0.7`，支持更多合法局域网 IPv4 地址。

## 1.1.8

- 停止无线投屏后增加“重新投屏”，目标仍在线时无需重新扫码。
- 明确区分扫码无线投屏、USB 辅助开启无线投屏和有线投屏，避免连接失败时误用其他通道。
- 增加可选流畅模式、低延迟音频参数和按字节计算的媒体导出进度。
- 改善网络切换、代理环境及特殊局域网地址下的连接兼容性。

## 1.1.7

- 修复无线投屏期间无法导出照片和视频的问题，无需额外连接 USB。
- 媒体扫描、预览和导出改为单任务执行，减少连续操作造成的卡顿或失败。
- Windows 手动连接页区分无线投屏与有线投屏，并改善切换网络后的设备识别和恢复提示。

## 1.1.6

- 增加投屏真实就绪确认，避免 ADB 已连接但 `scrcpy` 尚未成功时过早提示投屏成功。
- 同一扫码会话重复回调不会重复打开投屏窗口，已有投屏会直接复用状态。
- 改善 Windows 切换 Wi-Fi 后的连接稳定性，并保留一次有限恢复机会。
- 配套扫码投屏 `1.0.6` 可等待桌面端最终结果；新旧版本仍可交叉兼容。

## 1.1.5

- 改善长时间闲置、系统唤醒、网络变化及多台电脑轮流扫码后的连接恢复。
- 重复回调不会打开多个投屏窗口，停止后可再次使用仍有效的二维码启动投屏。
- macOS 减少钥匙串重复授权；Windows 简化防火墙提示并优化高 DPI 多设备界面。
- 恢复操作只影响当前目标，不中断开发工具或其他眼镜的 ADB 会话。

## 升级建议

- 桌面端建议使用 macOS 或 Windows `1.1.9`。
- 企业版 Glass3 优先使用较新系统内置的**扫一扫**应用，不需要额外安装独立扫码投屏 APK。
- 企业版系统较旧且暂时无法升级时，可以临时安装独立扫码投屏 `1.0.7` APK。
- 升级桌面工具后请重新生成二维码；旧二维码中的会话信息不应继续使用。
- macOS 请把新版本重新拖入**应用程序**目录并替换旧应用；Windows 请完整解压新版本，不要只替换 EXE。
