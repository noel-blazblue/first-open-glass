# API 参考

这里集中放置 Rokid Sprite Enterprise 相关接口文档。建议先按端侧进入对应 API，再根据能力模块定位具体接口、参数和回调。

## 按端侧选择

| 文档 | 适用场景 |
| --- | --- |
| [眼镜端 SDK API](./Glass3%20%20SDK(眼镜端)%20API文档.md) | 开发运行在 Rokid Glass3 设备上的眼镜端应用。 |
| [手机端 SDK API](./Glass3%20%20SDK(手机端)%20API文档.md) | 开发与眼镜配套的 Android 手机应用。 |
| [平台 OpenAPI](/openapi/ApiKey.md) | 接入平台 OpenAPI，管理消息、设备、智能体、远程协作和 AI 工作助手等能力。 |
