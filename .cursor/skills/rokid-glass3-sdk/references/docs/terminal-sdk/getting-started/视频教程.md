## 2. SDK 初始化与 ASR/TTS

这个视频说明 SDK 初始化流程，以及在线 ASR（语音转文本）和 TTS（文本转语音）的调用链路。

<video src="/02-SDK初始化与语音文本转化.mp4" controls width="1280x" height="720px" type="video/mp4">视频没有加载出来</video>

### 核心链路

| 能力 | 链路说明 |
| --- | --- |
| SDK 初始化 | 使用 SDK 能力前，需要先完成手机端和眼镜端初始化。 |
| 在线 ASR | 眼镜采集麦克风音频，通过蓝牙/P2P 到手机，再由手机转发到语音服务，识别结果返回眼镜展示。 |
| 在线 TTS | 眼镜端提交待播报文本，手机端转发到语音服务，服务返回音频流后在眼镜端播放。 |

在线 ASR/TTS 通常需要 API Key 鉴权信息。如需私有化语音服务，请查看：

- [ASR/TTS 私有化部署 SDK](/private-speech/SDK_INTEGRATION.md)
- [语音与 AI 示例](/代码示例/35-voice-ai/)
