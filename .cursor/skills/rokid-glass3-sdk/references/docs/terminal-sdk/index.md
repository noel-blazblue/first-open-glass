# SDK 文档

这里是 Rokid Sprite Enterprise 终端 SDK 的统一入口。开发者通常会先确认“我要接入哪一端、要实现什么能力、需要查哪个 API”，所以本页按接入路径组织资料。

## 先从这里开始

| 目标 | 推荐入口 | 你会看到什么 |
| --- | --- | --- |
| 第一次接入 SDK | [快速开始](getting-started/快速开始.md) | 调试线、投屏工具、环境要求、Maven 仓库和 SDK 依赖配置。 |
| 理清手机端和眼镜端职责 | [SDK 总览](getting-started/接入指南.md) | 眼镜端 SDK、手机端 SDK、专项 SDK、平台 OpenAPI 的边界。 |
| 按端侧查 API | [眼镜端 SDK](glasses/) / [手机端 SDK](phone/) | 每一端的接入说明、API 参考和示例代码。 |
| 按业务能力找资料 | [代码示例](/downloads/samples.md) | 设备连接、消息传输、媒体、语音与 AI、视觉识别、系统配置。 |

## 核心入口

| 入口 | 适用对象 | 重点内容 |
| --- | --- | --- |
| [眼镜端 SDK](glasses/) | 开发运行在 Rokid Glass3 上的眼镜端应用。 | 媒体采集、语音、识别、消息、设备状态、蓝牙、P2P。 |
| [手机端 SDK](phone/) | 开发与眼镜配套的 Android 手机应用。 | 设备连接、蓝牙、P2P、消息文件、媒体流接收、OTA、配置同步。 |
| [代码示例](/downloads/samples.md) | 已经知道要实现的功能，但不确定该看哪一端接口。 | 按业务场景查看 Demo 实现，并跳转到相关 API。 |
| [Demo 与下载](/downloads/) | 需要跑 Demo、找示例、下载应用或资料。 | Demo 运行指南、代码示例、常用资料、应用下载。 |

眼镜端和手机端 API 参考分开维护。你可以按当前开发的端侧进入对应文档；如果还不确定具体端侧，先进入 [API 参考总览](api-reference/) 按能力方向查找。

| 文档 | 适合查什么 |
| --- | --- |
| [眼镜端 SDK API](api-reference/Glass3%20%20SDK(眼镜端)%20API文档.md) | 眼镜端应用中的媒体、语音、识别、消息、文件、设备状态和外设能力。 |
| [手机端 SDK API](api-reference/Glass3%20%20SDK(手机端)%20API文档.md) | 手机端应用中的连接、P2P、蓝牙、消息文件、媒体流接收、OTA 和配置同步。 |
| [API 参考总览](api-reference/) | 不确定该看哪一端时，按能力方向快速定位接口章节。 |
