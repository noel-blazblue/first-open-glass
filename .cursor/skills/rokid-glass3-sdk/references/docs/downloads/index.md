# Demo 与下载

这里集中放置开发者接入时最常用的 Demo、代码示例、资料和下载入口。这个区域主要解决两个问题：先把 Demo 跑起来，再按能力找到可参考的代码。

## 推荐使用顺序

| 步骤 | 入口 | 用途 |
| --- | --- | --- |
| 1 | [Demo 运行指南](./demo-guide.md) | 获取 Demo 仓库，完成手机端和眼镜端工程构建。 |
| 2 | [代码示例](./samples.md) | 按设备连接、消息传输、媒体、语音与 AI、视觉识别等能力查找示例。 |
| 3 | [AI 开发助手 Skill](../terminal-sdk/resources/AI开发助手Skill.md) | 下载给 AI 编程工具使用的 SDK 知识包。 |
| 4 | [常用资料](../terminal-sdk/resources/使用手册与常用资料.md) | 查找使用手册、调试资料和常见集成资料。 |
| 5 | [应用下载](./apps.md) | 下载企业版应用、glassmate、远程协作等应用。 |

## 什么时候看哪个页面

| 你的问题 | 推荐页面 |
| --- | --- |
| 我还没有 Demo 工程 | [Demo 运行指南](./demo-guide.md) |
| 我想看某个能力怎么写 | [代码示例](./samples.md) |
| 我想让 AI 帮我基于当前文档和 Demo 开发 | [AI 开发助手 Skill](../terminal-sdk/resources/AI开发助手Skill.md) |
| 我需要手册、调试资料或补充文档 | [常用资料](../terminal-sdk/resources/使用手册与常用资料.md) |
| 我需要下载应用包 | [应用下载](./apps.md) |

## 使用建议

如果你正在接入某个能力，建议先跑通 Demo，再从代码示例进入对应场景，最后回到 [SDK 文档](/terminal-sdk/) 查看 API 参考、参数说明和回调说明。
